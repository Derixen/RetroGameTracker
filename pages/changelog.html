Changelog

The evolution of Retro Game Tracker

v0.2.1

Achievement Badge Improvements

  • Introduced circular retro pixel-art achievement badges.
  • Added automatic PNG loading from images/badges/.
  • Added Lucide icon fallbacks for missing badge images.
  • Improved badge alignment, spacing, and label readability.
  • Standardized game details headings with colored Lucide icons.
v0.2.0

Personal Achievements

  • Introduced a universal gaming achievement library.
  • Added achievement selection and earned badge display.
  • Added badge removal with confirmation.
  • Saved achievements to Supabase with private user ownership.
  • Prevented duplicate achievements per game.
v0.1.5

Personal Memories

  • Added one personal memory per game.
  • Added optional played year.
  • Implemented memory creation, editing, and deletion.
  • Added a dedicated empty state and improved memory presentation.
  • Strengthened database ownership constraints.
v0.1.4

Gaming History Improvements

  • Improved completion history presentation.
  • Refined completion management controls.
  • Improved game ownership checks for editing and deleting records.
v0.1.3

Navigation & Interface

  • Improved navigation and loading transitions.
  • Fixed loading overlay behavior across pages.
  • Refined game details layout and responsiveness.
v0.1.2

Game Details

  • Added dedicated game details pages.
  • Displayed game information and cover artwork.
  • Added soundtrack and walkthrough embeds.
  • Added personal gaming history presentation.
v0.1.1

Collection Management

  • Added personal collection management.
  • Introduced favorite and game status tracking.
  • Added collection search and browsing.
v0.1.0

Initial Release

  • Initial Retro Game Tracker application.
  • Supabase integration and user authentication.
  • Basic game collection functionality.
  • Responsive dark-themed interface.
